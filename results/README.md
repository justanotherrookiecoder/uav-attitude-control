# Simulation Results

This directory will contain the outputs and analysis from the UAV attitude-control experiments.

## Planned Results

- **Controller comparison:** Fixed-gain PID vs. gain-scheduled PID vs. MPC.
- **Robustness analysis:** Performance under different disturbance amplitudes.
- **Variable-inertia response:** Attitude tracking when the simulated moment of inertia changes.
- **Control effort:** Comparison of torque usage and actuator saturation.
- **Plots and data:** Exported figures and numerical results from MATLAB.

## Notes

Results will be added after verification of the simulation outputs and performance metrics. All reported values should include their simulation conditions and units.
